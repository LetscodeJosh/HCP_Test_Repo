📋 1. Executive Summary & Dual Pipeline Architecture

The Territory Reconfiguration Portal and HCP Profiling Mobile App share an enterprise bidirectional synchronization model. SFE Leads and District Managers can reconfigure territories via two robust pathways:

Pathway A: Embedded In-App Server (Offline / Field Wi-Fi Ready)

The mobile app executes an internal lightweight HTTP server (TerritoryWebServer) on port 8765. It serves the bundled single-page portal directly from Flutter assets to mobile browsers (Chrome / Safari) or laptop browsers via local Wi-Fi with ephemeral security tokens (?token=...). Real-time endpoints include:

  • GET /api/status: Server health, active port, version verification (V.0.6.2).
  • GET /api/live-data?program=...: Serves live ERPNext master data trees and doctor counts.
  • POST /api/sync: Acknowledges staged reconfigurations and synchronizes memory state.

Pathway B: Enterprise ERPNext Cloud Backend Pipeline

When running via desktop executable (Territory_Reconfiguration_Setup.exe) or Streamlit Cloud, the portal updates ERPNext v15 (dev.pmii-marketing.com) DocTypes (Territory, Sales Person, HCP Account) directly via authenticated REST APIs. The mobile app queries fetchTerritoryInfos(forceRefresh: true) and dynamically resolves territories via apiService.resolveUserTerritory().

🧪 2. Step-by-Step Simulation Scenarios

Option 1: 1-Device Mobile Simulation (Direct Handshake on Phone)

  1. Start Embedded Server: Open HCP Profiling App → Drawer → tap Territory Reconfiguration. Status confirms: Built-In Web Server Active (Port 8765).
  2. Launch Portal: Tap Open in Device Browser (Chrome / Safari) → opens http://127.0.0.1:8765.
  3. Reconfigure: In Territory Tree View or Table Grid View, find territory AD0101 (or RM101). Tap Quick Reconfigure → Reassign Assigned User ID to lesantos@pims-marketing.com → Save.
  4. Verify in Mobile App: Return to HCP Profiling App → tap + Add New Doctor → in Step 1, observe Territory Code and Territory Manager automatically pre-populated with reconfigured values!

Option 2: 2-Device Laptop-to-Mobile Wi-Fi Pairing Simulation

  1. Pair Devices: Connect laptop and mobile phone to the same Wi-Fi (or mobile hotspot).
  2. Scan QR / Open URL: In HCP App Territory Reconfiguration screen, copy the Laptop Wi-Fi URL (e.g. http://192.168.1.105:8765/?token=...) or scan on-screen QR code from laptop webcam.
  3. Execute Commercial Realignment:
    • Rename Code: Right-click AD0101 → Rename to ADC-T01.
    • Add Child Node: Under district AD1 - GMA/NORTH LUZON, click + Add Child Territory → code AD0199.
  4. Verify in Mobile App: Pull down to refresh on doctor list → new territory code is active across dropdowns and submission forms immediately.

Option 3: Live Cloud Backend Sync (dev.pmii-marketing.com)

  1. Launch releases/Territory_Reconfiguration_Setup.exe → log in with ERPNext credentials.
  2. Select territory (e.g., BA1-01 in Bayer or AD0102 in Abbott) → update assigned User ID / manager.
  3. Log into HCP Mobile App as that Medical Rep → App fetches fresh territory infos → doctor profiles reflect remapped territory.
