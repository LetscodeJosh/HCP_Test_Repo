2. Detailed Release Ledger (Part 1: V.0.4.7 to V.0.5.3)

V.0.4.7 • Multi-Clue Fuzzy Search & Acronym Resolution SEARCH INTELLIGENCE
  • What was applied: Developed LocationResolver.fuzzySearchInstitutions, replacing rigid substring checks with multi-token scoring.
  • Business & User Value: MedReps search by acronyms ("pgh", "slmc"), combined locations ("st lukes bgc"), or abbreviations ("makati med"), instantly finding institutions.
V.0.4.8 • Mandatory Workplace Geographic Resolution PSGC COMPLIANCE
  • What was applied: Built resolveCompleteWorkplaceLocation to resolve Region, Province, and City even when backend records lack location links.
  • Business & User Value: Guarantees 100% complete government-standard geographic data across all doctor submissions, eliminating administrative rejection loops.
V.0.5.0 • Dedicated Territory Reconfiguration Web Portal & Mobile Menu Launcher MAJOR SFE MILESTONE
  • What was applied: Engineered the dedicated Territory Reconfiguration Web Portal with interactive CSV preview, code renaming, and role-gated mobile drawer launch.
  • Business & User Value: SFE Leads and Administrators gained an executive desktop-grade realignment workspace, bypassing rigid ERPNext standard Desk screens.
V.0.5.1 • Built-In Embedded Local Web Server (Zero-Dependency Engine) LOCAL WEBSERVER
  • What was applied: Embedded an internal HTTP server (TerritoryWebServer) on port 8765 inside the mobile app with automated Wi-Fi IP and QR-code pairing.
  • Business & User Value: Eliminated ERPNext 404 Desk errors; allows instant pairing with laptops and iPads in the field with zero external web server dependencies.
V.0.5.2 • Interactive Studio Controls, Row Edit Modal & Native In-Page Notifications INTERACTIVE UX
  • What was applied: Replaced browser popup alerts with a dedicated dark-blue modal dialog (#editModalOverlay), search filters, and smooth floating toast notifications.
  • Business & User Value: SFE leads can edit territory codes, district clustering, and representative assignments with immediate in-page validation and real-time cascade stats.
V.0.5.3 • Dual-Tree Synchronizer & Cycle Snapshot Archive Vault DUAL-TREE ENGINE
  • What was applied: Built real-time side-by-side visualizer for Nested Set Territory Tree (`lft`/`rgt` boundaries) and Sales Person Tree, plus Cycle Snapshot Vault.
  • Business & User Value: Visualizes how surviving reps absorb restructured territories without losing historical doctor records; enables time-travel audit reviews of past cycles.

3. Detailed Release Ledger (Part 2: V.0.5.4 to V.0.5.8)

V.0.5.4 • Unified 27-Commercial-Program Selector & Dynamic URL Ingestion UNIVERSAL PROGRAMS
  • What was applied: Expanded portal dropdown to the complete official 27-program portfolio (Abbott DC, Bayer, RiteMed, Taisho, etc.) matching the mobile app.
  • Business & User Value: Full commercial portfolio alignment; switching programs updates territory lists, cascade matrices, and district targets in real time.
V.0.5.5 • Ultra-Clean Single-Line Browser URLs & High-Clarity QR Code Scanning OPTIMIZATION
  • What was applied: Streamlined browser URLs by 93% (reducing bulky query strings from 750+ characters to 53 chars) and added a 1-click "Copy Base IP" button.
  • Business & User Value: Transformed high-density QR codes into large-pixel, high-clarity QR codes that scan instantly on any laptop or phone camera, eliminating typing friction.
V.0.5.6 • Android 11+ Browser Launch Fix & HCP Profile Submissions Dark Navy/White UI ENTERPRISE STYLING
  • What was applied: Added package visibility queries to AndroidManifest to resolve Android 11+ external browser launch; themed portal data tables to match HCP Submissions.
  • Business & User Value: Guaranteed 100% reliable one-tap browser launching; established a unified visual identity (Dark Navy #0B192C headers + Pure White data rows + solid pill badges).
V.0.5.7 • Live ERPNext Production Sync, Zero Dummy Accounts & Blank Historical Cycles LIVE DATA FIDELITY
  • What was applied: Connected portal directly to live ERPNext DocTypes (Territory, Sales Person, HCP Account); purged 100% of mock doctor accounts.
  • Business & User Value: Absolute data authenticity — SFE simulation operates on real active doctors and actual field trees, rendering prior cycles blank (—) pending Excel upload.
V.0.5.8 • Pure-Text Professional UI, Hideable Left Sidebar & Accurate Tree Sync Engine ACTIVE PRODUCTION RELEASE
  • What was applied: Removed all decorative emojis for clean text labels; moved the 5 tabs to a collapsible left sidebar; added dropdown Cycle Vault; documented 6-phase sync.
  • Business & User Value: Maximizes screen space for multi-column territory grids; provides a clean, executive interface suitable for board presentations; guarantees atomic cutover.
