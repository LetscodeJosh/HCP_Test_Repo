3. Technical Implementation Plan for Paid GCP (Phases 1 - 3)

PHASE 1 CONTAINER
Production Alpine NGINX Containerization & Reverse Proxy DOCKER PROD
  • Build production Alpine NGINX container serving territory_reconfiguration_portal.html with strict security headers (HSTS, CSP, X-Frame-Options: SAMEORIGIN).
  • Configure NGINX reverse proxy to direct internal API calls directly to ERPNext with keepalive upstream connections.
# NGINX Production Proxy Configuration (nginx.conf)
server {
    listen 8080;
    server_name _;
    root /usr/share/nginx/html;
    add_header X-Content-Type-Options "nosniff";
    add_header X-Frame-Options "SAMEORIGIN";
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
    location / { try_files $uri $uri/ /index.html; }
    location /api/ {
        proxy_pass https://dev.pmii-marketing.com/api/;
        proxy_set_header Host dev.pmii-marketing.com;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-Proto https;
    }
}
