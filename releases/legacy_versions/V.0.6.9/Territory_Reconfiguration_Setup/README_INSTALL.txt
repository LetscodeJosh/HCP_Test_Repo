PIMS TERRITORY RECONFIGURATION WEB PORTAL - SFE LAPTOP EDITION
Version: V.0.5.2 (Build 28)
========================================================================

Overview:
---------
This application is the official standalone Territory Reconfiguration Portal
for Sales Force Effectiveness (SFE) Leads, MedReps, and Managers.
It provides full capability for:
- Viewing and searching territory trees and doctor assignments per program
- Reassigning MedReps and renaming territory codes
- Staging and committing live reconfiguration changes
- Centered 10-row pagination (10, 20, 30, 40, and All)
- Fixed checkbox and action columns for comfortable scrolling
- 100% offline-first operation with browser local storage persistence
- ZERO COMMAND PROMPT: Opens directly into your browser with no black terminal!

System Requirements:
--------------------
- Windows 10 or Windows 11 Laptop
- Any modern web browser: Google Chrome, Microsoft Edge, Brave, or Mozilla Firefox
- Python 3.x is OPTIONAL:
  * If Python is installed: Launches the background server at http://127.0.0.1:8765/
  * If Python is NOT installed: Opens the portal directly in your default browser
    with 100% complete offline features active!

Installation Methods:
---------------------
METHOD 1: Generic 1-Click GUI Installer (Recommended)
1. Double-click "Setup.vbs" (or "Setup.bat").
2. A clean installation prompt will appear. Click "Yes".
3. The installer copies all files to your personal profile:
   (%LOCALAPPDATA%\PIMS\TerritoryReconfigurationApp).
   * Note: NO administrator privileges or IT passwords are required!
4. A desktop shortcut titled "Territory Reconfiguration Portal" with the
   official PIMS icon will be created on your Desktop and Start Menu.
5. Double-click the Desktop icon anytime to open the portal.
   * NO Command Prompt or terminal window will ever open!

METHOD 2: Self-Extracting Standalone Installer (.EXE)
- Run "Territory_Reconfiguration_Setup.exe" located in the releases folder.
- It will automatically unpack and install the portal onto your laptop.

METHOD 3: Portable Zero-Install Mode
If you are testing from a USB flash drive or temporary folder without installing:
- Double-click "Open_Portal.vbs" (or "Run_Portable_Without_Install.bat").
- The portal will open immediately in your web browser with NO command prompt!

Uninstallation:
---------------
To cleanly remove the application and all shortcuts from your laptop:
- Open Start Menu > Programs > PIMS > Uninstall Portal
- Or run "uninstall.vbs" (or "uninstall.bat") from the installation folder.
